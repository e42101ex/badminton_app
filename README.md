# 🏸 羽球雙打配對

羽毛球雙打自動配對網頁 App。用貪婪加權演算法,平衡每個人的上場次數、休息、搭檔與對手多樣性。

## 功能

- 玩家名單管理(可暫停/恢復,不刪資料)
- 一次產生多輪賽程表
- 場地數即時提示(可開幾場、幾人休息)
- 公平輪數建議(🎯 按鈕循環 1~4 倍)
- 「每個人都當過隊友」所需輪數估算
- 可切換是否顯示每輪休息名單
- 一鍵「複製整場文字」貼到 LINE
- 資料自動存於瀏覽器(localStorage)
- PWA:可加到手機主畫面、離線使用

## 使用

單一 `index.html`,無相依套件。直接用瀏覽器開,或部署到任何靜態網站託管(如 GitHub Pages)。
