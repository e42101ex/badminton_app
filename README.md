# 🏸 羽球雙打配對

羽毛球雙打自動配對網頁 App。用貪婪加權演算法,平衡每個人的上場次數、休息、搭檔與對手多樣性。

## 兩種模式

**單面網模式** — 一次預先排好整場賽程表,適合只有一面網、大家輪流上場。

- 一次產生多輪賽程表
- 公平輪數建議(🎯 按鈕循環 1~4 倍)
- 「每個人都當過隊友」所需輪數估算
- 可切換是否顯示每輪休息名單

**多面網模式** — 即時派場,解決各面網不會同時打完的問題。

- 每面網獨立操作:打完按一下就自動排下一場
- 只從「當下沒在場上的人」挑人,絕不會排到還在別網比賽的人
- 等待名單顯示每個人等了幾場、共打幾場
- 可「只結束」暫停某面網,或「🎲 重抽」重新配對(不計入場數)
- 場地數調小時,進行中的比賽會保留到打完才移除

## 共通功能

- 玩家名單管理(可暫停/恢復;貼上多行名字可批次加入)
- 一鍵複製文字貼到 LINE
- 資料自動存於瀏覽器(localStorage)
- PWA:可加到手機主畫面、離線使用

## 使用

單一 `index.html`,無相依套件。直接用瀏覽器開,或部署到任何靜態網站託管(如 GitHub Pages)。
